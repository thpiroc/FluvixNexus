Fluvix Nexus の最初の公開版です。Files・Editor・Terminal・Git・Debug のパネルを自由に組み替えて使える、Windows 向けの軽量コードエディタです。

> English summary is at the [end of this page](#english).

## 動作環境

| 項目        | 内容                                                                                          |
| ----------- | --------------------------------------------------------------------------------------------- |
| OS          | Windows 11（x64）                                                                             |
| 確認した PC | Windows 11 Home 25H2（ビルド 26200）x64。インストール・起動・全機能・上書き・アンインストール |

Node.js・Python・.NET SDK・Git はアプリに含まれていません。必要な機能に応じて別途インストールしてください（[別途インストールするもの](#別途インストールするもの)）。

## ダウンロード

| ファイル                       | 内容                     |
| ------------------------------ | ------------------------ |
| `Fluvix-Nexus-Setup-1.0.0.exe` | インストーラー（x64）    |
| `SHA256SUMS.txt`               | インストーラーの SHA-256 |

ダウンロードしたファイルが壊れていないか・すり替わっていないかは、PowerShell で確かめられます（2つのファイルを同じフォルダに置いて実行します）。

```powershell
$expected = ((Get-Content .\SHA256SUMS.txt | Where-Object { $_ -like '*Fluvix-Nexus-Setup-1.0.0.exe' }) -split '\s+')[0]
(Get-FileHash .\Fluvix-Nexus-Setup-1.0.0.exe -Algorithm SHA256).Hash -eq $expected
```

`True` と表示されれば一致しています。`False` のときは実行せず、ダウンロードし直してください。

## インストール

1. `Fluvix-Nexus-Setup-1.0.0.exe` を実行します。ユーザー単位（`%LOCALAPPDATA%\Programs\fluvix-nexus`）にインストールされ、管理者権限は要りません。
2. 完了すると Fluvix Nexus が起動します。スタートメニューとデスクトップにショートカットが作られます。

- **コード署名をしていません。** Windows SmartScreen の「Windows によって PC が保護されました」が表示された場合は、「詳細情報」→「実行」で続行できます。**Smart App Control が有効な PC では、署名の無いアプリとして実行がブロックされることがあります。**
- **自動更新はありません。** 新しい版が出たら Releases からダウンロードし、同じ手順で上書きインストールしてください。上書きインストールでは設定や Debug Profile はそのまま残ります。Fluvix Nexus を起動したままインストーラーを実行すると、アプリは自動で終了し、インストール後に起動し直します。

## 主な機能

| 機能      | 内容                                                                                                                        |
| --------- | --------------------------------------------------------------------------------------------------------------------------- |
| Workspace | フォルダを開いて作業します。前回開いていたフォルダと、パネルの配置（分割・タブ・大きさ）は次回起動時に戻ります              |
| Files     | ファイルツリー / カラム表示、作成・改名・移動・コピー・削除（ごみ箱へ）、ファイル名検索・全文検索                           |
| Editor    | Monaco Editor、複数タブ、保存 / 別名で保存 / Auto Save、アプリの外での変更の検出                                            |
| Terminal  | 複数タブ。PowerShell / Node / Claude Code を起動できます                                                                    |
| Git       | 変更の一覧と差分、Stage / Commit / Push / Pull / Fetch、ブランチ、履歴、stash、remote、マージと競合の解決                   |
| GitHub    | フォルダを GitHub のリポジトリとして公開します（GitHub CLI が必要）                                                         |
| LSP       | JavaScript / TypeScript・Python・C# の補完、エラー表示、定義へ移動、参照、名前の変更、整形                                  |
| Debug     | Node.js・Python・C# の Breakpoint、Continue / Pause / Step / Stop、Call Stack、Variables、Debug Console                     |
| Settings  | 表示言語（日本語 / English）、Theme（Dark / Light）、Editor / Files / Terminal / LSP の設定、キーボードショートカットの一覧 |

## 別途インストールするもの

どれも**任意**です。入っていない機能だけが使えなくなり、画面に次の一手が表示されます（例:「Git が見つかりませんでした。」「LSP: 未インストール」「Node.js が見つかりません。」）。インストールした後は **Fluvix Nexus を再起動**してください。

| 機能                         | 必要なもの                                                                                              |
| ---------------------------- | ------------------------------------------------------------------------------------------------------- |
| Git パネル                   | [Git for Windows](https://git-scm.com/download/win)                                                     |
| GitHub へ公開                | [GitHub CLI](https://cli.github.com/)（`gh`）                                                           |
| LSP: JavaScript / TypeScript | `npm i -g typescript-language-server typescript@6`（**TypeScript 7 では動きません**。既知の制約を参照） |
| LSP: Python                  | `npm i -g pyright`                                                                                      |
| LSP: C#                      | `dotnet tool install -g csharp-ls`（.NET SDK が必要）                                                   |
| Debug: Node.js               | Node.js と vscode-js-debug 1.117.0（置き方は README）                                                   |
| Debug: Python                | Python と `pip install debugpy`                                                                         |
| Debug: C#                    | [netcoredbg](https://github.com/Samsung/netcoredbg/releases) と .NET（パスは ASCII 文字だけ）           |

詳しい手順はリポジトリの README.md の「別途インストールするもの」にあります。

## データとログ

| 内容                                                                             | 場所                                                        |
| -------------------------------------------------------------------------------- | ----------------------------------------------------------- |
| 設定・ウィンドウ / パネルの配置・最後に開いたフォルダ・Debug Profile・Breakpoint | `%APPDATA%\Fluvix Nexus`                                    |
| Node.js の Debug Adapter（利用者が置くもの）                                     | `%APPDATA%\Fluvix Nexus\debug-adapters`                     |
| ログ                                                                             | `%APPDATA%\Fluvix Nexus\logs\main.log`（と `main.old.log`） |

開いたフォルダの中と、インストール先には何も書き込みません。ログファイルでは絶対パスと認証情報を伏せています。

## アンインストール

Windows の「設定」→「アプリ」→「インストールされているアプリ」から Fluvix Nexus をアンインストールします。インストール先・ショートカット・アンインストール情報は削除されます。

次のフォルダは**アンインストール後も残ります**。不要であれば手で削除してください。

| フォルダ                              | 内容                                                                                                   |
| ------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| `%APPDATA%\Fluvix Nexus`              | 設定・Debug Profile・ログ（再インストールしたときに引き継ぐため、意図して残しています）                |
| `%LOCALAPPDATA%\fluvix-nexus-updater` | インストーラーが置く自分自身の写し（`installer.exe`、約 98 MB）。v1.0.0 では使われません（既知の制約） |

## 既知の制約

- 自動更新・コード署名はありません。Debug Adapter の同梱・自動ダウンロードもありません
- アンインストール後も `%LOCALAPPDATA%\fluvix-nexus-updater\installer.exe`（約 98 MB）が残ります。削除して問題ありません
- JavaScript / TypeScript の LSP は TypeScript 7 では起動しません（TypeScript 7 に `tsserver` が含まれないため）。グローバルには `typescript@6` を入れ、開いたフォルダに TypeScript 7 だけが入っている場合も補完などは使えません
- Debug 対象のプログラムは本物の端末を持ちません。標準入力・端末サイズ・色を使うプログラムは Debug Console では同じように動きません
- Breakpoint は行の挿入・削除に追従しません
- Debug を開始した後に Adapter が終了した場合、理由は画面ではなくログに残ります
- Variables は1回に 500 件までで、続きを読み込む操作はありません。Debug Console の行数に上限はありません
- C# の Debug は ASCII 文字だけのパスでのみ使えます
- Node.js の Debug では、Pause の理由が step と表示される、ESM の top-level で起きた例外では止まらない、などの違いがあります
- 実行が止まった位置を Editor で開くと、フォーカスも Editor へ移ります
- 画面（Renderer）はアプリに同梱したファイルだけを読み込みますが、仕組み上、PC 上のローカルファイルを読める状態にあります。外部のページやスクリプトを読み込まない構成で運用しており、将来の版で見直します

不具合や要望は [GitHub Issues](https://github.com/thpiroc/FluvixNexus/issues) で受け付けています。

## English

The first public release of Fluvix Nexus, a lightweight code editor for Windows with dockable Files, Editor, Terminal, Git and Debug panels.

- **Requirements:** Windows 11 (x64). Verified on Windows 11 Home 25H2 (build 26200) x64. Node.js, Python, .NET SDK and Git are not bundled; install them only for the features you use and restart the app afterwards.
- **Download:** `Fluvix-Nexus-Setup-1.0.0.exe` and `SHA256SUMS.txt`. Verify with `Get-FileHash .\Fluvix-Nexus-Setup-1.0.0.exe -Algorithm SHA256` against the value in `SHA256SUMS.txt`.
- **Install:** per user (`%LOCALAPPDATA%\Programs\fluvix-nexus`), no administrator rights. The installer is not code-signed: Windows SmartScreen may warn ("More info" → "Run anyway"), and Smart App Control may block it. There is no auto-update; install a newer version over the old one (settings are kept, a running app is closed and restarted).
- **TypeScript LSP:** use `npm i -g typescript-language-server typescript@6`. TypeScript 7 does not ship `tsserver` and does not work.
- **Data:** settings and logs are in `%APPDATA%\Fluvix Nexus` (`logs\main.log`). Nothing is written into the opened folder or the install folder.
- **Uninstall:** Settings → Apps. `%APPDATA%\Fluvix Nexus` and `%LOCALAPPDATA%\fluvix-nexus-updater` (an unused ~98 MB copy of the installer) remain and can be deleted by hand.
- **Known limitations:** see the Japanese list above (no auto-update / code signing, debug adapters are installed by the user, C# debugging needs ASCII-only paths, the renderer can read local `file://` URLs).
- **License:** MIT. Third-party licenses: `THIRD_PARTY_NOTICES.txt`.
- **Bug reports:** [GitHub Issues](https://github.com/thpiroc/FluvixNexus/issues). Please attach `main.log` and `main.old.log` from `%APPDATA%\Fluvix Nexus\logs`.
